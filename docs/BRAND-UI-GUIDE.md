# 화목 브랜드 UI 가이드

- 기준 이미지: `public/images/brand/`
- 적용 범위: 공개 페이지, 회원/쿠폰 화면, 직원모드, 관리자 화면의 공통 분위기와 UI 컴포넌트

## 브랜드 방향

화목은 쿠폰 시스템보다 장작구이 전문점의 인상을 먼저 전달한다. 홈페이지 첫 화면은 할인보다 매장, 불, 숙성 고기, 따뜻한 조명, 전문성을 먼저 보여준다.

핵심 인상:

- 장작불의 온기
- 검정 간판과 금빛 조명
- 숙성 고기 전문성
- 차분하고 고급스러운 매장 경험
- 모바일에서도 읽기 쉬운 운영형 인터페이스

## 기준 이미지 사용

| 파일 | 권장 용도 |

## 컬러

| 토큰 | 색상 | 용도 |
| --- | --- | --- |
| `charcoal` | `#0D0D0D` | 헤더, 푸터, 히어로 오버레이, 주요 텍스트 |
| `ember` | `#B13A1E` | 주요 CTA, 상태 강조, 불의 포인트 |
| `flame` | `#E06A2A` | 보조 강조, 인터랙션 |
| `warm-gold` | `#F7E6C1` | 로고 조명, 프리미엄 강조 |
| `paper` | `#F6F0E6` | 섹션 배경, 카드 대비 |
| `stone` | `#27231E` | 어두운 표면, 운영 화면 보조 배경 |

## 타이포그래피

- 본문은 시스템 산세리프를 유지해 관리 화면과 모바일 가독성을 우선한다.
- 큰 제목은 짧게 쓰고, 브랜드 메시지는 보조 문장으로 풀어쓴다.
- 버튼과 배지는 굵게, 설명문은 낮은 대비의 중립색으로 정리한다.

## 컴포넌트 원칙

- 카드 반경은 `8px` 이하로 유지한다.
- 쿠폰은 보조 혜택으로 표현하고, 랜딩 첫 화면은 매장 브랜드를 우선한다.
- 이미지는 실제 브랜드/메뉴 이미지를 사용한다.
- 페이지 배경은 밝은 `paper` 계열, 헤더/푸터는 `charcoal` 계열로 통일한다.
- 모바일은 1열, 태블릿은 2열, 데스크톱은 2-3열 구성을 기본으로 한다.

## 페이지 구성

- 홈: 브랜드 히어로, 장작구이 가치, 대표 메뉴, 운영 혜택 순서
- 화목소개: 브랜드 철학, 매장 분위기, 로고 응용 이미지
- 메뉴: 메뉴 이미지 중심 카드와 카테고리 필터형 시각 구조
- 쿠폰: 브랜드 경험의 보조 혜택으로 톤 다운
- 직원/관리자: 고급스러운 톤은 유지하되, 정보 밀도와 조작 효율을 우선
