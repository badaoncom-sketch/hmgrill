# 구현 로드맵

- 기준 문서: [화목-홈페이지 v1.0 기획설계서](../화목-홈페이지-v1.0-기획설계서.md)
- 작성일: 2026-07-05
- 목표: 단일 매장 운영에 맞는 공식 홈페이지와 QR 쿠폰 운영 시스템 구현

## 1단계. 프로젝트 기반 구성

- Next.js App Router 프로젝트 생성
- TypeScript, Tailwind CSS, Shadcn/ui 구성
- 기본 레이아웃, 라우트 그룹, 공통 컴포넌트 구조 정의
- 환경변수 예시 파일 작성
- Vercel 배포 기준 정리

상태: 1차 완료. Shadcn/ui는 외부 CLI 초기화 대신 프로젝트 내부 재사용 UI 컴포넌트로 먼저 구성했다.

검증 기준:

- 로컬 개발 서버 실행 가능
- 린트 통과
- 타입 체크 통과
- 프로덕션 빌드 통과

## 2단계. 데이터 모델과 인증 설계

- Supabase 프로젝트 연결
- 회원, 관리자, 직원 권한 모델 정의
- Supabase Auth 기반 회원가입 및 로그인 구현
- Resend 기반 이메일 인증 흐름 구현
- 사용자 프로필 테이블 및 인증 상태 저장

검증 기준:

- 이메일 인증 전 쿠폰 다운로드 제한
- 인증 메일 재발송 가능
- 인증 완료 후 마이페이지 접근 가능
- 권한별 접근 제어 동작

## 3단계. 쿠폰 발행 및 다운로드

- 관리자 쿠폰 발행 화면 구현
- 쿠폰 상태 `발행중`, `발행종료` 구현
- 발행수량, 사용기간, 재다운로드 정책 구현
- 회원 쿠폰 다운로드 정책 구현
- QR 쿠폰 토큰 생성 및 서버 조회 방식 구현

검증 기준:

- 동일 발행중 쿠폰 동시 중복 보유 방지
- 사용 후 재다운로드 정책 동작
- 회원당 1회 다운로드 정책 동작
- 발행수량 소진 시 자동 발행종료
- 발행중단 및 재발행 이력 유지

## 4단계. 회원 쿠폰 화면

- 쿠폰 다운로드 목록
- 내 쿠폰
- 쿠폰 사용내역
- QR 쿠폰 화면
- 사용 가능, 사용 완료, 기간 만료 상태별 화면 구현

검증 기준:

- QR에는 쿠폰 고유 토큰만 포함
- 쿠폰 정보는 서버에서 조회
- 만료 쿠폰은 QR 숨김
- 사용 완료 쿠폰은 재사용 불가

## 5단계. 직원모드

- 태블릿 전용 직원모드 화면 구현
- QR 스캔 입력 대기
- 쿠폰 조회 및 상태 확인
- 자동 사용완료와 직원 확인 후 사용완료 방식 구현
- 최근 처리 내역 표시

검증 기준:

- QR 리더기 키보드 입력 방식 대응
- 유효 쿠폰 조회 가능
- 이미 사용된 쿠폰 재사용 방지
- 기간 만료 쿠폰 사용 방지
- 사용 직원과 사용일시 기록

## 6단계. 관리자 운영 기능

- 대시보드
- 회원관리
- 직원관리
- 쿠폰관리
- 메뉴관리
- 이벤트관리
- 공지사항관리
- 문의관리
- 배너관리
- 팝업관리

검증 기준:

- 관리자 권한 없이는 접근 불가
- 쿠폰 이력 전체 조회 가능
- 통계 수치가 다운로드, 사용, 만료 이력과 일치
- 물리 삭제 없이 상태 변경으로 관리

## 7단계. 운영 검증과 배포

- 환경변수 점검
- Supabase RLS 정책 점검
- Vercel 배포
- 실제 QR 리더기 입력 테스트
- 직원 태블릿 브라우저 테스트
- 쿠폰 발행부터 사용완료까지 엔드투엔드 테스트

검증 기준:

- 운영 환경 빌드 성공
- 회원, 관리자, 직원 핵심 흐름 성공
- POS 미연동 운영 방식 문서화
- 장애 또는 오입력 시 복구 가능한 이력 구조 확보
