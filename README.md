# 화목 홈페이지

화목 홈페이지는 단일 매장 운영을 위한 공식 홈페이지 프로젝트이다.

현재 저장소는 Next.js 기반 1차 구현 단계이며, 핵심 목표는 회원가입 기반 QR 쿠폰 발행, 다운로드, 직원모드 사용 처리 시스템을 실제 운영 가능한 구조로 구현하는 것이다.

## 현재 상태

- 프로젝트 단계: 1차 앱 기반 구현
- 저장소 브랜치: `main`
- 주요 기준 문서: [화목-홈페이지-v1.0-기획설계서.md](./화목-홈페이지-v1.0-기획설계서.md)
- 구현 코드: Next.js App Router 기반 화면과 연동 준비 모듈 구성
- POS 연동: 범위 제외
- 프랜차이즈 기능: 범위 제외

## 핵심 기능 범위

- 회원가입 및 이메일 인증
- QR 쿠폰 발행, 다운로드, 사용 처리
- 회원 쿠폰함 및 사용내역
- 관리자 쿠폰, 회원, 직원, 메뉴, 이벤트, 공지 관리
- 태블릿 브라우저 기반 직원모드
- 쿠폰 다운로드, 사용, 만료, 재발행 이력 관리

## 예정 기술 스택

## 로컬 실행

```bash
npm install
npm run dev
```

검증 명령:

```bash
npm run lint
npm run build
```

## 개발 원칙

- 공식 문서 확인 후 구현한다.
- 설정값은 환경변수 또는 설정 파일로 관리한다.
- 테스트용 임시 코드와 사용하지 않는 기능 선구현은 금지한다.
- 쿠폰, 다운로드, 사용, 만료, 중단, 재발행 이력은 삭제하지 않고 상태와 이력으로 관리한다.
- 문서와 구현이 충돌할 경우 기획설계서를 먼저 확인하고, 필요한 경우 문서를 갱신한 뒤 구현한다.
